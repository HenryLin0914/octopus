# 章魚老師舞蹈教室 — 報到系統

LINE 官方帳號 + LIFF 網頁 + 自架後端（Node.js + SQLite），整套以 Docker 執行。

## 架構

| 部分 | 位置 | 說明 |
|---|---|---|
| 後端 | `server/` | `app.js` 商業邏輯與資料庫、`server.js` HTTP 入口。無第三方套件 |
| 家長端 | `public/index.html` | LINE 圖文選單開啟：報到、上課卡、出席、課表、請假、影片、綁定 |
| 管理後台 | `public/admin.html` | 總覽、週課表與排課、點名、學生、帳務（儲值與上課卡）、出席（紀錄、出席率、請假）、影片、設定 |
| 資料庫 | `data/octopus.db` | SQLite；每日自動備份到 `data/backups/`（保留 14 天） |
| 部署 | `Dockerfile`、`docker-compose.yml`、`deploy/install.sh` | |

根目錄的 `Code.gs`、`index.html`、`admin.html`、`config.js` 是舊的 Google Apps Script 版本，保留作為備援，切換完成後可刪除。

## 安裝到 VPS

1. DNS 新增 A 記錄，把網域指到 VPS。
2. 在自己的電腦執行（會詢問 LINE 的 Channel access token 與 Channel secret，輸入時不顯示）：

```bash
ssh -t root@henrylin.tw 'bash <(curl -fsSL https://raw.githubusercontent.com/HenryLin0914/octopus/main/deploy/install.sh)'
```

3. 依畫面最後的提示，到 LINE Developers 更新 LIFF Endpoint URL 與 Webhook URL。
4. 用 LINE 開後台，輸入畫面顯示的「安裝碼」成為管理員。

腳本可重複執行（用來更新或在 DNS 生效後補申請憑證）。主機上只會新增 `/opt/octopus`；80/443 沒人用時由容器內的 Caddy 處理 HTTPS，主機已有 nginx 時只新增一個獨立的站台設定檔。

## 日常操作（後台）

- **排課**：課表 → 課程管理 → 新增課程，選每週上課日、時間與開課期間（開始～結束日期），系統一次排完整期；結束日期留白則持續開課、自動往後排。課表可切換週／月檢視。單堂調課、代課、停課、加課都在課表上點該堂課處理。
- **停課／調課**：點課程 →「停課」或「調課／代課」，可選擇用 LINE 通知家長；有結束日期的課程停課時可順延一堂。月曆上選日期可「整天停課」（颱風假、國定假日）。同教室或同老師時間重疊時，儲存前會先警告。
- **老師備註**：點課程 → 老師備註，家長在 LINE 課表看得到，也可順便推播。
- **補課**：點名單或「出席 → 請假」按「排補課」，學生會出現在那堂課的點名單。
- **續開下一期**：編輯有結束日期的課程 →「續開下一期」，沿用時間、老師與學生。
- **點名**：總覽或課表點課程 → 按出席／請假／缺席；或顯示報到 QR Code 讓家長自己掃。
- **學生**：新增或批次匯入後把綁定碼給家長。點學生可儲值、排課、調整上課卡、解除家長綁定。
- **儲值與帳務**：「帳務」頁按「＋ 儲值」選學生與方案；同頁可看每月實收、每筆儲值明細（可更正或作廢）與所有上課卡。
- **兄弟姊妹（同一家庭）**：新增學生時選「兄弟姊妹」，或點學生 →「兄弟姊妹」設定。家長輸入其中一位的綁定碼就會全部綁定；已綁定的家長可由後台直接補綁。
- **共用上課卡**：儲值時勾選共用的兄弟姊妹；上課卡會顯示每個人各用了幾堂。
- **影片**：「影片」頁貼上 YouTube 連結（自動帶出標題與縮圖），選擇給全部家長、某門課或某位學生，可順便用 LINE 通知。家長點選單「影片」或傳「影片」給官方帳號即可觀看。
- **老師帳號**：老師用 LINE 開後台按「申請開通」，管理員在「設定 → 管理員與老師」開通。老師只能看課表與點名。
- **規則與通知**：全部在「設定」頁，改了立即生效。

## 開發

```bash
npm test                               # 後端流程測試
DEV_LOGIN=1 SETUP_CODE=dev npm start   # 本機啟動，http://localhost:8787/admin.html?dev=Uxxx 免 LINE 登入
```

`DEV_LOGIN` 只能用在本機，正式環境不要設定。
